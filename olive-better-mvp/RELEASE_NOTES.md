# 릴리스 노트

## 1.1.0

- 운영자 요청→근거 카드→수정→발행 흐름을 구현했습니다.
- 고객 전용 발행본 화면과 상세·좋아요·구매 반응을 구현했습니다.
- 고객 반응을 다음 초안의 점수·영역 순서·상품 수에 재적용합니다.
- 공개 검색 성공·제외·fallback 이유를 구분합니다.
- 잘못된 LLM 응답과 공급자 실패를 발행 가능한 성공으로 처리하지 않습니다.
- 고객 공개 API에서 내부 초안·제외 목록·운영 기록을 제거했습니다.
- 반응 영역과 상품의 실제 노출 조합을 검증합니다.
- 자동 테스트 21개, API E2E, 실브라우저 데스크톱·모바일 검증을 추가했습니다.
- 원본 데이터 부재를 명시한 300개 결정적 데모 카탈로그를 포함했습니다.
