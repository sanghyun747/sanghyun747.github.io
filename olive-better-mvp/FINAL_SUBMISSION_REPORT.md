# 최종 제출 보고서

## 제출 대상

- 프로젝트: Olive Better MD Automation MVP
- 실행 루트: 이 문서가 있는 `olive-better-mvp/`
- 운영자: `http://127.0.0.1:5173`
- 고객: `http://127.0.0.1:5173/customer.html`

## 구현 결과

- MD 요청 기반 공개 검색·정제·Well 해석
- 실제 LLM 호환 연결과 명시적 테스트 공급자 분리
- 품절·기능·Well·중복·금지 문구 상품 필터
- 운영자용 근거 카드, 검색, 수정, 발행 통제
- 고객용 발행 투영본과 상세·좋아요·모의 구매 기록
- 1/3/7점 반응을 다음 초안의 상품 점수·영역 순서·상품 수에 재적용
- 실패·fallback·차단 상태를 숨기지 않는 UI

## 정직한 제한사항

- 원본 300개 상품 파일 대신 알려진 분포를 맞춘 결정적 데모 카탈로그를 사용합니다.
- 실제 외부 LLM의 자격 증명 운영은 수행하지 않았고 어댑터는 주입 응답과 실패 계약으로 검증했습니다.
- 회원·결제·영구 DB는 MVP 범위 밖이며 구매는 행동 로그입니다.
- 공개 검색은 네트워크 실패 시 마지막 성공 캐시로 전환합니다.

## 제출 전 명령

```bash
npm test
npm run api:e2e
npm start
```

브라우저 자동화 도구가 있는 검증 환경에서는 다음도 실행합니다.

```bash
npm run browser:smoke
```

압축본, SHA-256 해시, Git 원격 커밋은 릴리스 단계에서 함께 고정합니다. 동일 소스의 롤백 체크포인트와 파일별 manifest도 보존합니다. Probe 제출은 사람이 직접 수행합니다.
