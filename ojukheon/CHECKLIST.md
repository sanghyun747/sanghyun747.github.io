# 한국관광콘텐츠랩 콘텐츠 활용 이벤트 — 참여 체크리스트

- 이벤트: 한국관광콘텐츠랩 콘텐츠 활용 이벤트 (공지 243)
- 기간: 2026-07-01 ~ **2026-08-31 (마감)**  / 당첨 발표 2026-09-09
- 결과물: 「율곡 이이의 길 — 오죽헌 디지털 답사기」 웹 매거진
- 공개 URL(예정): https://sanghyun747.github.io/ojukheon/

## STEP 1. 투어원패스 가입 (사용자 직접) — 필수
1. https://api.visitkorea.or.kr/#/comLogin/user 접속
2. 네이버 / 카카오 / 페이스북 / 구글 / 애플 중 하나로 소셜 로그인 → 투어원패스 가입
3. 가입 시 **휴대폰 연락처를 정확히 입력** (당첨 안내가 문자로만 오고, 3일 내 미회신 시 취소됨)

## STEP 2. 콘텐츠랩에서 관광 콘텐츠 다운로드 (사용자 직접) — 필수
> 다운로드 이력이 있어야 활용사례 등록 폼의 "다운로드 목록"을 채울 수 있음.
> **OpenAPI(인증키 호출)는 이벤트 제외 대상 — 반드시 웹에서 "다운로드" 방식으로 받을 것.**

- 관광 콘텐츠 찾기: https://api.visitkorea.or.kr/#/hubTourSearch
- 포토코리아(고품질 사진): https://api.visitkorea.or.kr/#/hubPhotoKorea
- 내 다운로드 내역 확인: https://api.visitkorea.or.kr/#/mypageUseData

### 받아올 목록 (검색어 → 받을 것)
- [ ] `오죽헌` → 고품질 사진 3~5장 (본채/몽룡실, 율곡매, 자경문, 오죽 대숲)
- [ ] `오죽헌` → 관광정보 텍스트(개요/이용안내/주소/운영시간) 1건
- [ ] `강릉` → 고품질 사진 2~3장 (경포호, 경포대, 강릉 전경 등 코스 연결용)
- [ ] `강릉` 또는 `강원` 관광정보 텍스트 1건
- [ ] (있으면) 오죽헌/강릉 관련 동영상 1건

받은 파일은 아래에 넣어주세요:
- 콘텐츠랩 다운로드 → `assets/conlab/`
- 직접 촬영한 오죽헌 사진/메모 → `assets/mine/`

파일명은 그대로 둬도 됩니다. 다운로드한 사진의 **원본 제목/설명/공공누리 유형**이 함께 오면 출처 표기에 그대로 씁니다.

## STEP 3. 웹 답사기 제작 (Claude 담당)
- [ ] 사용자 자료 + 콘텐츠랩 자료 배치
- [ ] 원고 작성 (직접 답사 서술 + 콘텐츠랩 관광정보 재구성)
- [ ] 출처 표기 `ⓒ한국관광콘텐츠랩` 전 이미지/텍스트에 삽입
- [ ] GitHub Pages 배포 및 URL 확인

## STEP 4. 활용사례 등록 (사용자 직접 제출, 문구는 Claude가 작성)
- 등록: https://api.visitkorea.or.kr/#/useUtilCase → "활용사례 등록"
- 폼 항목: 등록자 구분 / 이름 / 업종 / 활용 방법 / 활용 목적 / 서비스·제품명 /
  상세설명 / **다운로드 목록(체크)** / 대표이미지(썸네일) / 상세이미지
